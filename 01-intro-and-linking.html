Applied directly inside an HTML tag using the style attribute.

C. External CSS

Linked via an external file (01-introduction.css) using the <link> tag.

This box is entirely styled via the external stylesheet.

2. CSS Rule Anatomy

selector {
  property: value;
}

Selector: Targets the element (`h1`, `.card`, `#id`).
Declaration: Property + Value pair terminated by a semicolon.
